# Pre-release checklist

Internal build checklist tracked during initial development. Kept for history; not required reading for users. See [pre-release-audit.md](./pre-release-audit.md) for the broader open-source readiness review.

- [x] Build Docker image with opencode deps
- [x] Setup opencode config (local Ollama)
- [x] Use GitHub App auth as a replacement for SSH
- [x] Checkout git repo
- [x] Create branch
- [x] Accept opencode command to execute
- [x] Commit and push code
- [x] Document GitHub App install process — see [github-app-setup.md](./github-app-setup.md)
